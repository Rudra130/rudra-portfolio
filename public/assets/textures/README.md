# Assets — Celestial Textures

Contains high-resolution surface maps, normal maps, roughness maps, and specular maps for celestial bodies.

## Texture Specifications:
* `mercury_surface.webp` (1024x512) — Budh
* `venus_atmosphere.webp` (1024x512) — Shukra
* `moon_surface.webp` (1024x512) — Chandra
* `mars_surface.webp` (1024x512) — Mangal
* `jupiter_surface.webp` (2048x1024) — Guru
* `saturn_surface.webp` (2048x1024) — Shani
* `sun_surface.webp` (2048x1024) — Surya (optional, supplemented by GLSL corona shader)

> **Provenance**: Textures are sourced from permissible public NASA/USGS open repositories.
